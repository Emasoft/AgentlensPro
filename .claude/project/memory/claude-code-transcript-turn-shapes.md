# Claude Code transcript turn shapes

## Superseded

^ATOM-L7IT-Y08Y [desc: "a turn starts at a user record whose turnPosition is an object and isSidechain is not true: human prompts, heartbeats, task notifications; Stop-hook feedback and tool results carry no turnPosition", keywords: find_turn_start_in_transcript turnPosition_object turnOrigin_scheduled heartbeat_cron_prompt_record_shape task_notification_turn queued_command_attachment stop_hook_feedback_not_a_turn isSidechain_subagent_transcript origin_kind_human isMeta_user_record compact_summary_turn_start, ocd: 2026-10-14, lmd: 2026-10-14]
Claude Code transcript turn shapes, observed 2026-10-14 and corrected the same day after measurement on more than 130 real transcript entries. A turn starts at a record of type user whose turnPosition is an object and whose isSidechain is not true. That holds for human prompts (origin kind human), heartbeat cron prompts (turnOrigin scheduled, type user), task-notification turns and compact summaries. Heartbeat user records carry isMeta true, so isMeta must never exclude a turn start. turnPosition is absent on Stop-hook feedback (type user, isMeta true, no origin), on tool results, and on /clear and /exit. queued_command attachments carry task notifications, and one carried the heartbeat text mid-turn; six attachment records contain the heartbeat text and four sit mid-turn, so an attachment never starts a turn. Subagent transcripts carry no turnPosition. [^1]
