The Agent tool's isolation parameter is optional; only description and prompt are required. The review gate never asks for isolation. Review-fork launches in the AgentlensPro project: 267 without isolation (2026-10-05 to 10), then 57 with worktree isolation (2026-10-11 to 14); these counts are this project's, observed 2026-10-14. An isolated fork fails from a non-git working directory with 'Cannot create agent worktree: not in a git repository', and its worktree guard refuses complex git and fastedit commands. [^2]
