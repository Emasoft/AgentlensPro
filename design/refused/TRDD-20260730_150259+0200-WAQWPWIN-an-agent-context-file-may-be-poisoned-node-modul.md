**Finding (a GitHub Actions workflow is vulnerable, severity `critical`):**

**AICTX-001** (ai-context-poisoning, severity `critical`)

**What:** A file the AI reads as INSTRUCTIONS (CLAUDE.md, a skill, an agent definition, a rule) contains authority impersonation, invisible unicode, or a jailbreak pattern.

**Why it matters:** This is the highest-leverage attack on an agentic system: the payload does not exploit the code, it exploits the reader — and the reader has the user's full privileges.

**Fix to attempt:** Do not 'clean it up' silently. Preserve the file, show the user the exact payload and where it came from, and strip the covert unicode only after they have seen it.

## Approval log

- 2026-07-31T16:40:55+0200 — REFUSED by USER (tier 3, relayed by the main Claude). The headline and
  the evidence describe different things. `AICTX-001` fires on "a file the AI reads as INSTRUCTIONS
  contains authority impersonation, invisible unicode, or a jailbreak pattern"; what was found is
  `generateAgents.js:56`, a `writeFile(\`.claude/agents/${agent.name}.md\`, …)` call in third-party
  library code that Claude never reads as instructions and that carries no payload. The real risk —
  a dependency writing files Claude later loads as instructions — lives at the INVOCATION, and that
  is already guarded: `.claude/settings.json` registers a `PreToolUse(Bash)` deny on
  `scripts/deny-playwright-init-agents.js`, and playwright's `scripts` field is `undefined`, so
  installing it runs nothing. Approving would dispatch an agent to edit a file inside
  `node_modules/` — third-party code we do not own, regenerated by every `pnpm install`, so the
  edit would be both improper and erased. The prescribed fix ("strip the covert unicode") has no
  referent here.

## Notes and lessons learned

1. The detector is worth keeping; its FRAMING is what failed. "A dependency contains a code path
   that can write agent-context files" is a useful signal — but it is a *capability*, not a
   *compromise*, and reporting it as `critical` under a poisoned-file headline sends the reader
   looking for a payload that does not exist. A capability finding should name the invocation as
   the mitigation point, which is where a guard can actually be placed. Fed back upstream in
   ai-maestro-janitor#151.
